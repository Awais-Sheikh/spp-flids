# SPP-FLIDS: privacy, robustness and heterogeneity in federated intrusion detection (Edge-IIoTset)

Code and raw results for the study *"Federated Intrusion Detection for Heterogeneous IoT Networks: An Empirical Study of
Privacy, Robustness and Data Heterogeneity on Edge-IIoTset"* (preprint).

The study evaluates FedAvg, FedProx, update clipping, client-level Gaussian differential privacy and a **simulated** secure
aggregation protocol on the 15-class Edge-IIoTset benchmark with ten clients and three random seeds. All tuning decisions use a
validation split; test results are computed once per run.

## Repository layout

| Path | Content |
|---|---|
| `code/spp_flids_run_all.py` | Main experiment runner (centralized baseline, heterogeneity, FedProx, privacy-utility, ablation, label flipping, secure-aggregation benchmark). Writes `results.json`. |
| `code/spp_flids_supplement.py` | Supplementary runner (per-client class distributions, PR-AUC / ROC-AUC and curves, measured timing, reproducibility check). Writes `supplement.json`. |
| `results/results.json` | Raw results of the main run (all seeds, per-class F1, confusion matrices, validation curves). |
| `analysis/analysis.py` | Loads `results.json`, removes a duplicated bookkeeping record, computes means, paired differences, confidence intervals and Holm-adjusted p-values. |
| `analysis/make_*_figures.py` | Scripts that regenerate the result figures from `results.json`. |
| `figures/` | Figures generated by the scripts. |

## Data

The Edge-IIoTset dataset is **not** included. Download it from Kaggle ("Edge-IIoTset Cyber Security Dataset of IoT & IIoT",
file `Edge-IIoTset dataset/Selected dataset for ML and DL/ML-EdgeIIoT-dataset.csv`) and check the dataset licence before
redistributing anything derived from it. Original dataset paper: Ferrag et al., IEEE Access 10 (2022) 40281-40306.

## Reproducing the experiments (Kaggle)

1. Create a Kaggle notebook and attach the Edge-IIoTset dataset.
2. Paste `code/spp_flids_run_all.py` into one cell. Run it first with `QUICK_TEST = True` (about 10 minutes), then set
   `QUICK_TEST = False` and use **Save & Run All (Commit)**. The full run took about 3.8 hours on CPU.
3. Do the same with `code/spp_flids_supplement.py` (about 1 hour) for the supplementary measurements.
4. Place the resulting JSON files in `results/` and run the scripts in `analysis/`.

Random seeds are fixed (0, 1, 2); the client partition also changes with the seed.

## Main findings (test macro-F1, mean over 3 seeds)

* Centralized MLP: 0.795; FedAvg with IID clients: 0.792.
* Label skew lowers FedAvg to 0.758 (Dirichlet alpha 0.5) and 0.645 (alpha 0.1); FedProx (mu 0.001) gave no detectable benefit.
* Clipping alone: 0.738 (alpha 0.5). Adding noise: 0.715 at sigma 0.05 (epsilon about 536 with secure aggregation, about 4,400 without),
  0.620 at sigma 0.1, divergence at sigma 0.3. No setting combined a meaningful privacy budget with usable accuracy.
* With 20% label-flipping clients, FedAvg falls to 0.589 and 22% of test samples receive the flipped label; the clipped and noised
  pipeline keeps 0.684 and 1.3%.

## Limitations (see the paper for the full list)

* One dataset, one small MLP, ten clients, three seeds (low statistical power).
* Secure aggregation is a **simulation** of pairwise masking; its communication overhead is an analytical estimate.
* The privacy budgets come from an own implementation of Renyi accounting for client-level DP (honest-but-curious server, full
  participation, no dropout or collusion) and have not been cross-checked against a library accountant.
* Payload, URI and port columns were removed; categorical encoding was fitted before the train/test split.
